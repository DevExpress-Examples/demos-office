This demo uses the **DevExpress Word Processing Document API** to remove sensitive data from documents. You can use the sample file or supply your own document. To do the latter, select **Upload a File** in the file selection drop-down menu. 

In the **Document Sanitation Settings** panel, select data types to remove from the document. Use the **Sanitize and Save as...** dropdown button to select the output format, update the file, and download the result.
